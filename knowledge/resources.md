# Resources & APIs

## Hosting
- **Hostinger:** SSH key auth, deploys to ~/domains/unklefunk.music/public_html/
- **GitHub:** github.com/unkfunkproduction (or similar)

## Music Platforms
- **Traxsource:** https://www.traxsource.com
- **Beatport:** https://www.beatport.com

## API Keys (stored in .env — not tracked in git)
- OPENAI_API_KEY — OpenAI Assistants API (Agency Swarm)
- XAI_API_KEY — xAI / Grok (Hermes)
- GITHUB_TOKEN — GitHub repo access
- SEARCH_API_KEY — Web search for music discovery

## Hermes Config
- Location: ~/.hermes/
- Config: ~/.hermes/config.yaml
- Env: ~/.hermes/.env
- Skills: ~/.hermes/skills/house-music/
- Cron jobs: weekly-discovery (Fri 9am), monthly-chart (1st), sunday-slackin-prep (Sun 8am)
